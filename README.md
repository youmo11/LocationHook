# 📍 LSPosed 定位Hook模块

基于LSPosed框架的Android定位模拟模块，支持固定位置、路线模拟、高德地图集成，专为出行场景设计。

## ✨ 功能特性

### 核心功能
- 🌍 **全局定位模拟**：Hook所有应用的GPS、网络、混合定位
- 🗺️ **高德地图集成**：内置地图选择器、路线规划、地址搜索
- 🚶 **路线模拟**：支持步行、驾车路线模拟，可导入高德导航路线
- 📱 **应用级控制**：支持白名单/黑名单模式，精确控制Hook范围
- 🔄 **实时更新**：支持自定义位置更新间隔，模拟真实GPS漂移
- ⚡ **极速响应**：LSPosed原生Hook，性能几乎无损耗

### 实用功能
- 一键切换常用位置（家、公司、常用地点）
- 位置抖动模拟，防止被检测为虚拟定位
- 支持海拔、精度、速度、方向模拟
- 路线循环模式，模拟通勤路线
- 导出/导入路线数据
- 支持高德/百度/谷歌坐标互转

## 🚀 快速开始

### 1. 申请高德地图Key
1. 访问 [高德开放平台](https://lbs.amap.com/) 注册账号
2. 创建应用，获取Android端API Key
3. 包名填写 `com.locationhook.module`
4. SHA1获取：运行 `keytool -list -v -keystore ~/.android/debug.keystore`，默认密码`android`

### 2. 配置Key
修改 `local.properties` 文件：
```properties
AMAP_API_KEY=你的高德地图Key
```

### 3. 编译安装
```bash
# 编译Release版本
./gradlew assembleRelease
```

### 4. LSPosed激活
1. 在LSPosed中找到"定位Hook模块"并启用
2. 选择要Hook的应用（或全局模式）
3. 重启设备生效

## 📖 使用说明

### 基础使用
1. 打开APP，在地图上长按选择要模拟的位置
2. 点击"启用模拟"按钮
3. 打开其他APP验证位置是否已修改

### 路线模拟
1. 在地图上选择起点和终点
2. 点击"路线规划"，选择出行方式（步行/驾车）
3. 调整模拟速度（默认18km/h）
4. 点击"开始模拟"开始沿路线移动

### 应用级控制
1. 进入"应用管理"页面
2. 选择工作模式：
   - **全局模式**：Hook所有应用（除系统应用）
   - **白名单模式**：只Hook选中的应用
   - **黑名单模式**：不Hook选中的应用
3. 选择要控制的应用即可

## ⚙️ 功能说明

### 定位参数配置
| 参数 | 说明 | 建议值 |
|------|------|--------|
| 定位精度 | 模拟的GPS精度 | 10-20米 |
| 更新间隔 | 位置更新频率 | 1000-3000毫秒 |
| 位置抖动 | 模拟GPS漂移 | 0-20米 |
| 模拟速度 | 路线模拟速度 | 1.4m/s（步行）- 16m/s（驾车） |
| 连续模式 | 路线走完后循环 | 开启/关闭 |

## 🛡️ 防检测特性
1. **真实GPS信号模拟**：包含海拔、速度、方向、精度等完整字段
2. **时间戳校准**：时间戳与系统时间严格对应，包含elapsedRealTime
3. **位置抖动**：模拟真实GPS漂移，不会固定在一个点纹丝不动
4. **随机延迟**：位置更新间隔随机波动，防止被检测为固定间隔
5. **Bundle字段**：包含正常位置返回的额外字段，如卫星数、信噪比等

## 📝 常见问题

### Q: 定位不生效？
A: 
1. 确认LSPosed中模块已启用，并且选择了目标应用
2. 确认目标应用已完全重启（可以重启手机）
3. 检查系统定位服务是否开启
4. 尝试关闭其他定位相关模块

### Q: 部分应用检测到虚拟定位？
A:
1. 开启"位置抖动"功能，设置抖动半径5-10米
2. 降低更新间隔到1000毫秒以内
3. 启用"模拟传感器"功能（需设备支持）
4. 关闭系统"允许模拟位置"设置（LSPosed模式下不需要这个权限）

### Q: 高德地图API报错？
A:
1. 检查Key是否正确，包名和SHA1是否匹配
2. 确认网络连接正常
3. 检查高德开放平台是否开通了相关服务权限
4. 查看日志中的错误码，对照高德API文档排查
